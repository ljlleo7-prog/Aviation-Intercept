# UI Design System - Aviation Cockpit Theme

## Design Philosophy
Unified dark aviation cockpit aesthetic with cyan/blue tech accents, consistent typography, and futuristic HUD elements.

## Color Palette
- **Primary Background**: `#0a0e27` (Deep space blue)
- **Secondary Background**: `#141b3d` (Dark navy)
- **Accent Cyan**: `#00ffff` (Bright cyan glow)
- **Accent Blue**: `#00d4ff` (Electric blue)
- **Text Primary**: `#e8f4f8` (Off-white)
- **Text Secondary**: `#8fa3b0` (Muted blue-gray)

## Typography
- **Primary Font**: Orbitron (tech/futuristic headings)
- **Monospace Font**: Share Tech Mono (data displays, HUD elements)

## Key Visual Elements
- Clipped corners (polygon clip-path) for tech aesthetic
- Cyan glowing borders and text shadows
- Animated scanline effect
- Grid background pattern
- Glass morphism panels with backdrop blur
