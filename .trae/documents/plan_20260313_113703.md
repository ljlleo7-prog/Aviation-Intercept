# NPC Response Pipeline with Ollama & Supabase

I will implement a robust NPC response system that generates, stores, and serves context-aware dialogue for the First Officer (FO) and Cabin Crew.

## 1. Database Schema (Supabase)
I will create a new table `skylinetragedy_npc_responses` to store the generated dialogue.
- **Columns**:
  - `scenario_id`: Event trigger (e.g., `engine_fire`, `taxi`, `summon_fo`)
  - `role`: `FO` or `CABIN_CREW`
  - `difficulty`: `rookie` to `devil` (affects accuracy/tone)
  - `content`: The actual dialogue text
  - `vagueness`: 0-100 score
  - `stress`: 0-100 score

## 2. Generation Script (`scripts/generate_npc_responses.js`)
A Node.js script to populate the database using Ollama (Llama3).
- **Logic**:
  - Iterates through all defined failure scenarios (from `EngineFailures.js`, etc.) and normal flight phases.
  - Generates **5 unique variations** for each combination of Scenario + Role + Difficulty.
  - **Difficulty Logic**:
    - *Low Difficulty*: Clear, accurate, calm, helpful.
    - *High Difficulty*: Vague, stressed, potentially inaccurate, delayed.
  - Upserts results into Supabase.

## 3. NPC Crew Service (`src/services/NPCCrewService.js`)
A runtime service to manage crew behavior.
- **Features**:
  - **Event Listeners**: Listens for system failures and phase changes.
  - **Response Selection**: Fetches relevant responses from Supabase (cached for performance).
  - **"Summon" Mechanic**:
    - Handles user requests to talk to crew.
    - **Difficulty Modifier**: High difficulty introduces latency or "ignored" requests (requires multiple summons).
  - **State Tracking**: Tracks crew stress levels to influence future responses.

## 4. Integration (`FlightInProgress.jsx`)
- Initialize `NPCCrewService`.
- Connect to the UI to display crew messages (distinct from ATC/Radio).
- Add controls to "Summon FO" or "Call Cabin" if not already present.

## 5. Verification
- Run the generation script to populate the DB.
- Test in-game:
  - Trigger an engine failure.
  - Verify FO responds appropriately based on difficulty settings.
  - Verify "Summon" latency in 'Pro'/'Devil' modes.
